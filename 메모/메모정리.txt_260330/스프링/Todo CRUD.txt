아이디와 비밀번호를 사용한 Basic 인증

HTTP의 특성
무상태(stateless) : 이전 통신을 기억하지 않는다.
- 매 요청마다 인증정보를 함께 전달해야 한다.
- 개인정보가 유출 될 수 있다.

회원가입
로그인

토큰 기반인증
- 사용자가 인증에 성공한 후 토큰을 발급받아, 서버와의 통신에서 인증을 처리하는 방식
- 토큰은 클라이언트의 브라우저의 저장이 된다. (자동로그인, 아이디 기억)

JWT(JSON Web Token)
- JSON 형식으로 사용자 정보를 저장하고 서명을 통해 토큰의 무결성을 검증하는 방식

구조 
헤더 : 해싱 알고리즘, 토큰의 타입
페이로드 : 사용자 또는 시스템 관련 정보
서명 : 헤더와 페이로드를 Base64로 인코딩 한 뒤, 비밀키로 암호화한 문자열

JWT 토큰 생성 및 반환 구현 
- 유저 정보를 바탕으로 헤더와 페이로드를 작성하고 서명을 한 뒤 토큰을 반환하자

OneperRequsetFilter : HTTO 요청 1번당 필터 로직이 한 번만  실행되도록 도와주는 Spring 필터기반 클래스

doFilterInternal() : HTTP 요청이 들어오면 이 필터가 실행이 되고 커스텀 필터를 만들때 필터처리로직을 작성하는 매서드 

HTTPSerbletRequset request : 클라이언트가 보낸 HTTP보낸요청
HTTPSerbletResponse response : 클라이어트에게 보낼 HRRP응원벙보
FiterChain filterChain: 다음 필터로 요청을 전달하는 객체

StringUtils.hasText(bearerToken) :  문자열 유효성 검증 메서드
- null값인지 확인
- ""빈 문자열인지 확인
- 공백만 있는지 확인
- 실제 문자열이 있는지 확인
