stored  program
MySQL 서버 안에 저장해두고 실행하는 프로그램 단위
프로그램의 종류
- 프로시저: 여러 SQL 작업을 묶어서 실행하는 프로시저
- Function : 값을 계산해서 반환하는 함수
- Trigger : insert, update, delete 발생할 떄 자동실행
- Event : 정해진 시간마다 자동실행

Stored program 문법
-MySQL안에서 프로그래밍 언어처럼 SQl을  실행하기 위한 문법
문법의 종류
-변수
-조건문
-반복문
-예외처리
-커서
-BEGIN ~END 블록

프로시저(procedure)
- 여러개의 SQL문을 하나의 이름으로 저장하고, 필요할 떄 호출해서 실행하는 기능

- 자주 사용하는 SQL을 간단하게 사용할 수 있다.

기본구조 
delimiter //
create procedure 프로시저명(매개변수)
begin
     sql문
end //
delimiter ;

포시저 호출 방법
call 프로시저()

프로시저 삭제 방법
drop procedure if exists 프로시저명;

매개변수
in : 외부에서 값을 받아서 프로시저 내부로 전달
out : 프로시저 안에서 만든 값을 외부로 전달
inout : 값을 받아서 수정한 뒤 외부로 전달

키워드 변수명 자료형,
키워드 변수명 자료형

세션변수
- 전역변수(static 변수 느낌)
- 현재 MtSQL 접속에서 사용할 수 있는 변수
