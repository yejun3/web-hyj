case문 
- 조건에 따라 다른 값을 반환하는 문법
case
       when 조건 then 결과1
       when 조건 then 결과2
       when 조건 then 결과3 
       else  기본결과
end

case 컬럼명
       when 값1 then 결과1
       when 값2 then 결과2
       when 값3 then 결과3 
       else  기본결과
end

- case문은 select절에서 많이 사용된다.
-order by절에서도 사용할 수 있다. -> 비즈니스 로직 기준 정렬(업무 우선순위, 처리순서, 긴급도)
- group by절에서도 사용할 수 있다.
- update쪽에서도 조건에 맞게 데이터를 수정할 수 있는 장점

begin

MySQL의 예외처리
Handler
-Procedure 안에서 에러,경고 조회결과 없음 같은 상황을 처리하는 예외처리 문법
- 프로시저 실행중 문제가 생겼을때 프로시저가 바로 중단되지 않도록 처리방법을 정해두는 문법

에러처리 : 중복된 PK를 INSERT한 경우
조회결과 없음 처리 : select..into의 결과가 없는 경우
커서종료 처리 : 더 이상 읽을 데이터가 없는 경우
ㄴ CURSOR : SELECT 결과를 한 줄씩 꺼재서 처리하는 기능
경고 처리 : 데이터 잘림, 형 변환 경고 등

기본문법
declare 핸들러타입 handler for 예외
begin
예외처리
end;

핸들러 타입 종류
continue : 에러 처리 후 다음 문장 계속 실행
exit : 에러 처리 후 begin -end 블록 종료

예외 종류
SQLEXCEPTION : 대부분의 SQL 에러
SQLWARNING : SQL 경고
NOT FOUND : 조회결과 없음
MySQL 에러코드 : 1062 (중복키 에러)
