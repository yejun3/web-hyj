다중  선택자
클래스를 여러개 지정한다.

<p class="a,b,c"> 내용 </p>

CSS에서 멀티클래스 선택하기

EX) a,b,c 클래스 모두 가지고 있는 태그를  선택하기
.a.b.c{..}

자손 선택자
<div class="a">
        <div class="b">
            <div class "c">
         </div>
</div>

.a .b 
# 띄어쓰기가 있을 경우 a클래스 안에 b클래스를 지정
# 띄어쓰기 없이 붙어있을 경우 a와 b를 모두 가지고 있는 클래스를 지정
.a .c
#(공백은 자손도 상관없이 지정할 수 있음)

- 자식 선택자

                <a>메뉴2</a>

인접 형제 선택자
뒤에 있는 형제 하나를 선택

<h1>제목</h1>
<p>문단1</p>
<p>문단2</p>

h1 + p {...}

일반 형제  선택자
뒤에 있는 형제 모두를 선택

h1 ~p{...}

<input type="text" placehoder="이름입력">

input[type] : input 태그 중에서 type 속성을 가진 태그를 선택

input[type="text"]{...} : input 태그중에서 type="text"를 가진 태그를 선택

의사 클래스 선택자
- 사용자의 행동이나 상태를 선택

:hover
마우스를 올렸을 떄

:active
: 클릭하는 순간

button: active{..}

:focus
입력창을 선택했을 때

input:focus{...}

:checked
체크박스가 선택됐을때

input:checked{...}

:disabled
비활성화 상태일 때

input:disabled{...}

:enabled
활성화 상태일 때

input:enabled{...}

구조 의사 클래스
-위치에 따라 선택

:frist-child
첫번째 자식을 선택

li:first-child{...}
첫 번째 자식을 선택

:li:last-child{..}
마지막 자식을 선택

:nth-child(n){...}
n번쨰 자식을 선택

:nth-child(even){...} ->짝수 자식 선택
:nth-child(odd){...} ->홀수 자식 선택

BEM 방법론
클래스 이름을 너무 일반적으로 작성하면 겹칠 수 있으니까 역할을 구체적으로 지정해서 식별을 하자

Block : 독립적으로 존재할 수 있는 큰 덩어리
ex) header, nav, card, product-card, login-form, profile, footer....

Element : 블록 안에 포함되는 구성요소
- Element는 혼자 존재하기 보다는 Block안에서 의미가 있다.

Modifier : Block이나 Element의 상태 또는 변형을 의미한다.
ex) product-card product-card--sale

<article class="product-card">
          <div class="product-card_image"> 상품이미지</div>
          <h2 class="product-card_title">무선마우스</h2>
           <p class="product-card_price">29000</p>
           <button class="product-card_btn">구매하기</button>
</article>
