데이터 조작 프로시저 테스트

SQL* PLUS : 프로그램
- 오라클에서 재공해주는 명령어 기반 프로그램
- 오라클 데이터배이스에 접속해서 SQL문을 작성하고 실행할 수 있다.

SQL 버퍼(Buffer) 사용
- 임시 저장공간이 존재한다.
- 이전에 실행했던 SQL이 저장이 된다.

프로시저를 실행했는데 예상한 결과와는 다르다 -> 그 이유를 찾아야 함

1. 입력값이 제대로 들어왔는지
2. select결과는 존재하는지
3. UPDATE 조건은 맞게 썼는지
4. COMMIT 필요한지 (INSERT.UPDATE,DELETE)
5. 예외가 발생하지는 않았는지

SQL* PLUS 명령어 유형
파일 
SAVE - 버퍼에 들어있는 명령어를 파일로 저장
GET - 파일의 내용을 SQL 버퍼로 불러온다.
SPOOL - 실행 결과를 파일로 저장한다.
*편집*
L(LIST) - 현재 SQL 버퍼 내용을 확인한다,
A(APPEND) - 현재 줄 끝에 내용을 추가한다.
C(CHANGE) - 문자열을 변경한다.
I(INSERT) - 새로운 내용을 추가
DEL - 현재줄을 삭제 
// SQL > DEL 2(원하는 줄 번호) 
    (원하는 부분을 삭제할 수 있음 2번쨰 줄 삭제 )
*실행*
RUN - 버퍼의 SQL을 실행한다.
/ -SQL 버퍼의 내용을 바로 실행한다.
START - SQL파일을 실행한다.
@ - SQL파일을 실행한다.
환경
SET SERVEROUTPUT - 출력한 내용을 화면에 표시하도록 설정
DEFINE - 변수를 선언
ACCEPT - 출력형식 지정
TTITLE - 상단 제목출력
BTITLE - 하단 제목 출력

PL/SQL 테스트를 위한 SQL *PLUS 의 활용
- PL/SQL은 변수, 조건문, 반복문, 예외처리 등을 사용해서 

테스트항목
실행이 되는가 : 문법 오류 없이 실행이 되는지 확인
출력이 맞는가 : 예상한 값이 출력이 되는지
데이터가 바뀌었는가 : INSERT , UPDATE , DELETE 결과를 확인한다. -> COMMIT
오류가 없는가 : SHOW ERRORS를 통해 오류를 확인
조건별 결과가 맞는지 : 정상값, 잘못된 값, NULL값 등을 넣어 결과를 확인한ㄷ.

DMBS_OUTPUT 패키지
- PL/SQL 처리 결과를 화면에 출력하기 위해 사용
- PUT_LINE() 메서드가 메세지 끝에 줄바꿈을 포함하여 출력
- 프로시저나 함수 사이에 단계별 출력문을 넣어서 테스트를 한다.

프로시저 테스트

2. 프로시저 실행
3. 실행 후 데이터 확인
4. 의도대로 작동되지 않으면 디버깅
