- 하드웨어. 소프트웨어 자원을 관리한다.
-CPU, 메모리, 디스크 등을 프로그램에 할당한다.
-CPU와 메모리를 직접 제어해야 한다.
- 여러 프로그램을 동시에 실행하기가 어렵다.

2.운영체제의 종류 구분하기
Windows
- 개인용, 중소규모 서버에 많이 사용된다.
-GUI를 사용한다.
LINUX
- 오픈소스이다.
- 서버환경에서 많이  사용된다.
UNIX
- 안정성이 높고 대규모 서버 환경에 사용된다.

3.신뢰도 요구사항 분석하기
온라인 쇼핑몰 서버는 24시간 운영되어야 한다.
운영체제 선정시 신뢰도가 중요한 이유를 쓰시오

- 서버가 장기간 안정적으로 동작해야 하기 떄문이다.
- 운영체제 장애 발생 가능성을 줄여야 한다.
- 메모리 누수 발생시 성능 저하가 일어날 수 있다.
- 보안 패치 및 버그 수정 사 안정적인 운영이 필요하다.
- 서버중단 시 결제 오류와 서비스 장애가 일어날 수 있다.

4. 메모리 누수 설명하기
-개념과 문제점에 대해서 설명하기
개념
- 프로그램이 사용한 메모리를 반납하지 않은 현상
문제점
메모리 사용량이 계속 증가한다.
- 서버 속도가 느려진다.
- 프로그램 오류가 발생 할 수 있다.
- 결국 서버를 재기동할 필요가 있다.

5. 동시 사용자 처리 분석하기
수강신청 시스템에서 오전 9시에 학생 5000명이 동시에 접속하였다.
운영체제가 처리해야 하는 작업을 서술하시오

- CPU 사용량 분배
- 메모리 할당
- 네트워크 연결 관리
- 프로세스 스케줄링
- 사용자 요청 처리 순서 결정

6. 대용량 파일 처리 요구사항 분석하기
영상 업로드 서비스에서 운영체제의 파일 처리 성능이 중요한 이유를 작성하시오

대용량 파일 저장 작업이 많기 떄문이다.
디스크 I/O 성능이 중요하다.
 ㄴ 디스크의 파일을 읽어오거나 불러오는 역할(input), 저장하는 역할(output)
여러 사용자가 동시에 업로드를 할 수 잇다
파일 저장 속도가 느리면 서비스 성능이 저하된다.
서버 과부화가 일어날 수 있다.

8.  운영체제 선정 시 공급베너의 기술지원이 중요한 이유
- 장애 발생 시 빠른 대처가 가능 
- 보안 패치를 안정적으로 받을 수 있다.
- 공식문서와 메뉴얼을 제공받을 수 있다.
- 유지보수가 쉬워진다.
- 장기 지원버전을 사용할 수 있다.

9. 사용자가 많은 운영체제를 사용하는 장점을 설명하세요
- 검색 자료가 많다.
- 문제해결 방법을 쉽게 찾을  수 있다.
- 커뮤니티 활동이 활발하다.
- 예제 코드와 기술 문서가 풍부하다.
- 유지보수 인력을 구하기가 쉽다.

10. Linux가 서버 환경에서 많이 사용되는 이유
- 무료이며 오픈 소스이다.
- 자유로운 수정이 가능하다.
- 서버환경에 최적화 되어있다.

11. 운영체제에 드라이버가 필요한 이유
- 운영체제와 주변기기 사이를 연결하기 떄문이다.
- 운영체제가 장치를 인식할 수 있게 해준다.
- 프린터, 웰켐 그래픽 카드 등을 사용할 수 있게 해준다.

12. 리눅스가 저사양 서버에서도 많이 사용되는 이유
- CLI 환경으로 운영이 가능하다.
- 메모리 사용량이 적다.
- 하드웨어 요구사항이 상대적으로 낮다.
- 서버 비축 비용을 절감할 수 있다.
