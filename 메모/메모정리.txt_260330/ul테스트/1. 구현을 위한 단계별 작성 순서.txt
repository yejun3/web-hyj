3. 핵심 개념 및 배경지식 설명
이 프로그램을 완전히 이해하기 위해 필요한 개념과 그에 따르는 배경지식입니다.

1. HTTP 쿼리 스트링 (Query String)과 @RequestParam
설명: 사용자가 웹 서버에 데이터를 전달할 때 주소창 뒤에 덧붙이는 형태(?key=value)의 규격입니다.

배경지식:

GET 방식의 HTTP 요청은 보통 데이터를 URL에 포함하여 보냅니다. ?name=홍길동에서 ?는 쿼리스트링의 시작을 알리고, name은 변수명(Key), 홍길동은 값(Value)이 됩니다.

스프링 컨트롤러에서는 @RequestParam 어노테이션을 사용해 이 주소창에 담겨온 값을 자바의 메서드 매개변수(String name)로 매핑하여 추출해 냅니다.

2. URI 인코딩 (encodeURIComponent)
설명: 웹 주소(URL)에는 띄어쓰기, 한글, 특수문자 등이 올바르게 전달되지 못하고 깨지는 현상이 발생합니다. 이를 전 세계 공통의 특수한 기호(ASCII 코드 문자열)로 변환해 주는 작업입니다.

배경지식:

예를 들어 한글 "홍길동"을 주소창에 그냥 넣으면 브라우저나 서버 환경에 따라 글자가 깨질 수 있습니다. encodeURIComponent("홍길동")을 실행하면 %ED%99%8D%EA%B8%B8%EB%8F%99 같은 안전한 문자열로 변환하여 에러 없이 전송되도록 보장합니다.

3. 비동기 통신과 fetch() API
설명: 페이지 전체를 새로고침(F5)하지 않고도, 백그라운드에서 서버에 데이터를 요청하고 결과만 받아와 화면 일부분만 바꾸는 기술(AJAX)의 현대적인 자바스크립트 도구입니다.

배경지식 (Promise 객체):

서버에 데이터를 요청하고 응답을 받는 데는 시간이 걸립니다. 자바스크립트는 응답이 올 때까지 프로그램을 멈추고 기다리는 대신, Promise(약속) 객체를 사용해 "언젠가 응답이 오면 실행할 작업"을 예약해 둡니다.

.then()은 그 예약 작업을 처리하는 문법입니다. response.text()로 응답 데이터(글자)를 해독한 뒤, 다음 .then(data => ...) 블록에서 그 글자를 받아 화면에 뿌려주는 흐름을 가집니다.
