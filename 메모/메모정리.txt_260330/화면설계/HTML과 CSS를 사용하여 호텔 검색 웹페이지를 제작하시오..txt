HTML과 CSS를 사용하여 호텔 검색 웹페이지를 제작하시오.

이 웹페이지는 상단 메뉴, 검색 영역, 추천 호텔 목록, 하단 영역으로 구성된다.

호텔 목록은 카드 3개를 가로로 배치하는 방식이 아니라, 세로 리스트형으로 제작하시오.

각 호텔 항목은 다음 구조로 배치하시오.

왼쪽: 호텔 이미지
오른쪽: 호텔 이름, 설명, 가격, 예약 버튼

1. 전체 구조

다음 구조를 반드시 포함하시오.

<header>
<main>
    <section class="search-section">
    <section class="hotel-section">
<footer>
2. Header 영역

Header에는 다음 내용을 작성하시오.

왼쪽
Hotel Finder
오른쪽 메뉴
호텔검색
예약확인
고객센터
Header 스타일 조건
display: flex 사용
로고와 메뉴를 양쪽 끝에 배치
세로 가운데 정렬
배경색은 흰색
아래쪽 테두리 추가
좌우 여백은 50px
메뉴 hover 조건

메뉴에 마우스를 올리면 다음 효과가 적용되어야 한다.

글자색이 초록색 계열로 변경
크기가 1.12배 커짐
변화는 0.3초 동안 부드럽게 진행
3. 검색 영역

검색 영역에는 다음 내용을 작성하시오.

제목
나에게 맞는 호텔을 찾아보세요
설명
지역명이나 호텔명을 입력하면 추천 숙소를 확인할 수 있습니다.
검색 박스

검색 박스에는 다음 요소를 포함하시오.

<input>
<button>

input의 placeholder는 다음과 같이 작성하시오.

예: 제주, 부산, 강릉

버튼 문구는 다음과 같이 작성하시오.

검색하기
검색 박스 스타일 조건
검색 박스는 흰색 배경
최대 너비 800px
가운데 정렬
display: flex 사용
input은 남은 공간을 차지하도록 작성
그림자와 둥근 모서리 적용
검색 박스 hover 조건

검색 박스에 마우스를 올리면 다음 효과가 적용되어야 한다.

위로 6px 이동
그림자가 더 진해짐
변화는 0.3초 동안 부드럽게 진행
input focus 조건

input을 클릭하면 다음 효과가 적용되어야 한다.

테두리 색상 변경
바깥쪽에 옅은 그림자 효과
기본 outline 제거
4. 호텔 목록 영역

추천 호텔 3개를 세로로 배치하시오.

각 호텔 항목은 다음 구조를 가져야 한다.

이미지 | 호텔 정보

즉, 하나의 호텔 항목 내부에서 이미지는 왼쪽, 텍스트 정보는 오른쪽에 배치한다.
