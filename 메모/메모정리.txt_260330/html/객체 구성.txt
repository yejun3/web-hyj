- `new Object()`는 **빈 객체를 생성**하고 그 객체의 내부 프로토타입을 `Object.prototype`으로 설정한다
- 반환값은 일반 객체이며, 속성을 자유롭게 추가할 수 있다

```jsx
const person = new Object();

person.name = "홍길동";
person.age = 25;
person.job = "개발자";
```

- `in` : 특정 속성이 객체에 포함되어 있는지 확인하는 방법

```jsx
console.log('name' in person) //결과는 true or false로 반환
```

- `for-in` 문을 사용하면 객체에 포함된 모든 프로퍼티에 대해 순회를 수행할 수 있다.

```jsx
for(i in person){
	console.log(`${i} = ${person[i]}`);
}
```

//템플릿 리터럴
  : `${}`를 사용하면 `` 안에 코드에서 변수자리에{}를 씌우기만 하면 연산자를 쓸 필요 없이 나옴

console.log(i + " = " + person[i]); // 기존방식

console.log(`${i} = ${person[i]}`); // 템플릿 리터럴 사용

## 메서드

- 메서드는 **객체 안에 정의된 함수**로, 해당 객체가 할 수 있는 동작을 나타낸다.
- 함수(function)와 문법은 같지만, 객체를 통해 호출될 때 그 객체가 문맥(`this`)이 된다

### 메서드 생성 방법

```jsx

const user = {
  name: '민수',
  sayHello: function() {
    console.log('안녕하세요!');
  }
};
```

### **this**

- `this`는 “현재 객체 자기 자신”을 가리킨다.

```jsx
const user = {
  name: '민수',
  sayHello() {
    console.log(`안녕하세요, 저는 ${this.name}입니다.`);
  }
};

user.sayHello(); // 안녕하세요, 저는 민수입니다.
```

- `this.name` → 이 메서드가 속한 객체(`user`)의 `name` 속성을 가져온다.
- 즉, `this`는 “이 메서드를 가지고 있는 객체”를 가리킨다.
