document 객체
- 현재 웹 페이지 전체를 의미하는 객체이다

<html>
           <head>
                    <title>제목</title>
            </head>

           <body>
                    <h1>안녕하세요</h1>
                     <p>자바 스트립트 공부중</p>
            </body>
</html>

브라우저는 저 코드를 화면에만 그리는 게 아니라 객체로도 만들어준다.

document 객체가 필요한 이유
- javaScript는 HTML을 직접 수정할 수 없다.
- 반드시 document를 통해 접근을 해야한다.

<h1 id="title">안녕하세요</h1>

- CSS 선택자로 태그를 선택하는 방법도 있음

document 객체가 하는 일
- HTML 요소 찾기
- 글자 변경
- 이미지 변경
- CSS 변경
- 새로운 태그생성
- 태그삭제 
등을 할 수 있다.

document의 대표적인 메서드
document.write() -> 문서에 글자를 출력한다.
* body에 있는 내용은 지우고 출력을 하기 때문에 실무에서는 많이 쓰지 않는다.

document.createElement() -> 새로운 태그를 만든다.(만드는 역할만 함)

document.body -> 웹 페이지의 body 에 접근을 한다.

body.appendChild(요소); -> 부모의 요소의 마지막 자식으로 새로운 요소를 추가하겠다.

꼭 body가 아니라 내가 js로 선택한 태그의 자식으로도 추가할 수 있다.

변수(varible)
 뱐수 선언 할때  vat, let, const 같은 키워드를  사용한다.

var : 에전에 사용하던 변수 선언 키워드
- 같은 변수명으로 재사용이 가능하다.
- 대입이 가능하다.
- 같은 이름의 변수를 실수로 여러번 만글어도 오류가 발생하지 않아서 버그가 생기기 쉽다.

let: 값이 변경될 수 있는 변수를 선언하는 키워드
let 변수명 = 값;
- 대입은 가능하다.
- 같은 변수명으로 재선언하는 것은 불가능하다.

const : 값이 변경되지 않는 상수를 선언하는 키워드
- 상수를 선언할 떄 값을 초기화해야 한다.
- 대입을 할 수없다.
- 같은 이름으로 재선언을 할 수 없다.
- 변하면 안되는 값을 저장할 때 사용한다.
