화살표 함수

(매개변수) => {...};

매개변수가 없으면 소괄호 생략 불가능
1개일 떄 생략 가능
2개일 떄 생략 불가능

return이 있으면 키워드와 함꼐 중괄호 생략이 가능하다.

classList 프로퍼티
- html 요소의 class 속성을 자바스크립트로 추가, 삭제변경, 확인 할 떄 사용하는 프로퍼티
element.classList -> 요소의 클래스 목록을 가져온다.

element.classList.add("클래스명1",'클래스명2") : 클래스를 추가

element.classList.remove("클래스명") : 요소에서 클래스를 삭제

element.classList.contains("클래스명") : 요소에 해당 클래스값을 가지고 있는지 검사

element.classList.toggle("클래스값") : 요소에 해당 클래스값이 있으면 삭제, 없으면 주차

element.classList.replace("기존값","바꾸려는 값:) : 해당 클래스의 값을 바꿈
