5. 테이블 생성

반려동물 진료 예약 정보를 저장하기 위한 reservation 테이블을 생성하세요.

다음 조건을 만족하도록 테이블을 작성합니다.

컬럼   자료형   설명
id   BIGINT   예약 번호, Primary Key, 자동 증가
pet_name   VARCHAR(50)   반려동물 이름
owner_name   VARCHAR(50)   보호자 이름
animal_type   VARCHAR(30)   동물 종류
doctor_name   VARCHAR(50)   담당 수의사
reservation_date   DATE   예약 날짜
status   VARCHAR(20)   예약 상태
price   INT   예상 진료비

테이블 생성 예시는 다음과 같습니다.

CREATE TABLE reservation (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    pet_name VARCHAR(50) NOT NULL,
    owner_name VARCHAR(50) NOT NULL,
    animal_type VARCHAR(30) NOT NULL,
    doctor_name VARCHAR(50) NOT NULL,
    reservation_date DATE NOT NULL,
    status VARCHAR(20) NOT NULL,
    price INT NOT NULL
);

문제 3. 모든 예약 정보 조회

데이터베이스에 저장된 모든 진료 예약 정보를 조회하는 기능을 구현하세요.

요청 방식은 다음과 같습니다.

GET /reservations

DAO 조건

ReservationDAO에 다음 메서드를 작성하세요.

List<ReservationVO> findAll();

DAO 조건

ReservationDAO에 다음 메서드를 작성하세요.

List<ReservationVO> findAll();

DAO는 MyBatis Mapper와 연결되도록 작성합니다.

Mapper XML 조건

Mapper XML에 다음 SQL을 작성하세요.

SELECT *
FROM reservation

Mapper의 namespace는 DAO 클래스의 전체 경로와 일치해야 합니다.

예:

<mapper namespace="com.korea.petclinic.dao.ReservationDAO">
Service 조건

DAO의 findAll() 메서드를 호출하여 결과를 Controller에게 반환합니다.

Controller 조건

다음 주소로 요청을 받습니다.

GET /reservations

조회 결과를 JSON으로 반환합니다.

문제 8. 검색 기준 선택

사용자가 전달한 searchType 값에 따라 다른 기준으로 예약 정보를 검색하세요.

사용 가능한 검색 기준은 다음과 같습니다.

pet     : 반려동물 이름 검색
owner   : 보호자 이름 검색

GET /reservations/search-detail?searchType=pet&keyword=초코
GET /reservations/search-detail?searchType=owner&keyword=김민수
GET /reservations/search-detail?searchType=doctor&keyword=이준호

문제 9. 진료비 정렬

진료 예약 정보를 예상 진료비 순으로 정렬하여 조회하세요.

사용자가 sort 값을 전달합니다.

asc  : 가격 낮은 순

desc : 가격 높은 순

요청 예시:

GET /reservations/sort?sort=asc

결과:

가격이 낮은 예약
↓
가격이 높은 예약

다음 요청의 경우:

GET /reservations/sort?sort=desc

결과:

가격이 높은 예약
↓
가격이 낮은 예약
